## [release/0.3.1] - 2026-11-01

### 🐛 Bug Fixes

- *(web)* Keep the serialization task of query results alive. In 0.3.0, every SELECT response of the SPARQL endpoint was empty.
- *(web)* Support the standard `text/tab-separated-values`, `text/turtle`, and `text/n3` media types in content negotiation.
- *(web)* Return `406 Not Acceptable` if content negotiation fails and `400 Bad Request` for SPARQL syntax errors.
- *(cli)* Register an in-memory object store for `memory://` locations.
