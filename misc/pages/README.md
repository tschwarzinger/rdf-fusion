# RDF Fusion Website & Playground

This directory contains the source code for the RDF Fusion website and the interactive playground.

## Architecture

The following technologies enable the easy creation of static content while still allowing for the rich interactivity
needed for the playground:

*   **Hugo**: Acts as the primary static site generator. It handles routing, documentation, layouts, and standard
    content pages.
*   **Svelte**: Used for complex, stateful components—specifically (e.g., playground). Svelte components are compiled
    into plain JavaScript which are then used to populate the HTML generated by Hugo.
*   **WebAssembly**: The Svelte playground interacts with a Wasm build of the `rdf-fusion` crate, allowing queries to
    run entirely locally in the browser.

## Setup

You will need the following tools installed:
1. **Hugo**
2. **Node.js & npm** (for generating Svelte-based pages and bundling CSS/JS assets)

Install the frontend dependencies:
```bash
npm install
```

## Development & Testing

Running the site locally requires two separate processes: one to bundle the JavaScript/Svelte code, and one to serve the
Hugo site.

1. **Compile Frontend Assets:**
   Use Rollup to compile the Svelte components, Bootstrap, and FontAwesome into the `static/generated/` directory.
   ```bash
   npx rollup -c -w
   ```
   *(The `-w` flag watches for file changes and rebuilds automatically).*

2. **Run the Hugo Server:**
   In a separate terminal, start the Hugo development server:
   ```bash
   hugo server -D
   ```

3. **View the site:**
   Navigate to the address shown by Hugo.

> **Note on WASM Testing:** If you are testing changes to the RDF Fusion engine or the JavaScript bindings, you must
> compile the WASM bindings in the `lib/wasm` directory (`wasm-pack build --target web --dev lib/wasm`) and upload the
> resulting `.wasm` and `.js` files via the Playground's version manager UI.
